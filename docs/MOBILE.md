## 获准设备工作的顺序

1. 本轮明确设备授权，选择唯一serial；无线端口动态变化，不复用旧端口当永久地址。
2. 记包名/版本/firstInstallTime和必要显示设置；刷新完整备份并在电脑预检。
3. 内部核验候选证书/包名/递增versionCode，不输出指纹或摘要。
4. 同身份 `adb -s <serial> install -r <apk>`；首个独立个人版另记并行安装。
5. 读回版本/启动/首次安装时间，核对设置、分类、ID、明细、金额、日期与关系。
6. 恢复/迁移写入先隔离往返、损坏拒绝、回滚，获得具体真实写入授权才执行。
7. 冷启动/持久性/UI分别记录，失联和未执行不是通过；恢复曾改动的旋转/息屏值。

不卸载/clear，不降级，不在真实数据造删除或金额修改测试。旧功能在最新兼容候选组合验收。
迁移应保留ID/ext/类型/日期/未知字段；数据库与设置都核对，不能只看数量。
