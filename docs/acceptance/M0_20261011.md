本地验证入口：`scripts/test-local.ps1`。构建入口：`scripts/build-personal-android.ps1`，显式指定候选名称和递增 code；成功后生成忽略目录内的候选与台账。不会安装或发布。

两份候选保存在 `local-artifacts/android`；最新为 `cheki-0.0.0-m0.2-11001.apk`。第二次复用相同工具链、依赖锁和下载缓存，只递增候选版本；通过构建脚本实际核对 APK 身份、签名、显示名与版本。最终本地验证再次通过 analyze、25 项流程回归和 4 项应用测试。候选尚未安装，Android 交互、可访问性及设备冷启动均未验证。

首次构建问题保留：旧 SDK 元数据 404、Windows 桌面插件符号链接、首次 Dart 编译错误、Gradle/Google Maven 下载、AGP 新 DSL、Properties 命名冲突、新 Android CLI 安装 NDK、下载断流和共享 SDK 目录未持久。已逐项处理，具体过程在本包 Changelog 同一行，不以跳过门槛替代修复。

环境复用：现有 JDK 和 Android SDK 平台/工具沿用已有版本，SDK 工具复制到 CountTools 独立目录。新增 Flutter 固定 SDK、Gradle 独立缓存、NDK、插件所需 API 35 和 CMake；原 SDK、SalaryFlow 配置和签名不改。
