## 改动与边界

- 颜色解析支持旧 HEX、简写 HEX、明确不透明 ARGB 和整数 RGB；非法或透明值保持未知，不猜颜色、截断范围或丢弃透明事实。黑色 0 与未知 NULL 分开，白色保留中性描边。
- 取色器提供红、粉、橙、黄、绿、蓝、紫、黑、白预设。HEX 与 R/G/B 各 0–255 的输入、256 档滑块和原有画布互相更新预览；非法代码或 256 等越界值阻止确认，修正后恢复可操作。取消或系统返回不改变调用者；对话框确认回到成员表单，最终保存才写入成员配置。
- 记录、成员选择等现有页面直接读取成员配置色；转团新身份沿用原色，改名不重置颜色。后续统计按同一配置色读取，属于 M3，尚未实施。新增成员不按姓名或团体猜色。
- 四项 Cheki checkbox、默认无背签及已确认的领取、尺寸、背签规则不变。
