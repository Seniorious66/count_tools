## 实际变化

管理新增「数据导入与导出」，支持完整 CSV 多表数据包、空交易模板、格式和关联检查、数量差异预览及明确确认。数据包覆盖所有表及成本/状态/参与/流水关系，同时携带设置、附件、原始库和序列。空模板清除业务行、设置和附件并压实数据库，保留结构、迁移账本和固定初始尺寸。

交易模式只追加新稳定 ID，相同内容跳过、冲突整批拒绝；批次 ID 不能换内容重用。完整快照独立恢复整份账本，库存及历史不重复累加。两种模式都在隔离副本完成全业务检查，使用已有持久事务提交，失败保留原代；制作预览期间或预览后账本变化均拒绝覆盖。无用的自有工作副本清理与历史代保留分开。

保持 schema 8 和旧备份格式。原 ID、created_at、occurred_on、领取原时间、金额原文、缺键、NULL、未知字段、BLOB、ext、修订和审计不重建。序列不回退，不把未知成本补0，不按名字合并成员，不造旧库存或现金输入。完整格式与操作见[数据携带说明](../TRANSPORT.md)。
