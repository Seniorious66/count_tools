# Cheki 登记修订：日期、成员与默认值

2026-10-11，WF-009。用户本轮指示优先于 [WF-008 修订](CHEKI_CHANGE_20261011.md) 的冲突条款；原文和已结束规划保留追溯。当前范围、依赖及状态以 MasterSheet 为准。

后续 WF-010 已修订为无签/有签/宿题互斥、条件背签及扣券明细常开，冲突条款以 [最新属性修订](CHEKI_ATTRIBUTES_20261011.md) 为准。下文保留 WF-009 当时规则。

## 1. 日期和操作时间

Cheki 发生信息只到天，逻辑字段 `occurred_on` 为业务日期。登记、核对、详情及编辑均不要求发生时间点。所有 Cheki 数量、成员及属性统计继续按该日期归属，日/周/月/年/所有的筛选、成员每日入口和设置色保留。

创建动作在确认时单独写入 `created_at` 时间戳，精确到秒；修改动作写 `updated_at` 和修订审计，不改变原 `created_at`。原型新建/修改用真实动作时刻，合成种子使用明确的示例录入时间。存储时间戳与日期不是同一个字段，不能把日期补成午夜并称为真实发生时间。

迁移已存在的业务时间点时，按固定业务时区派生日期，并保留原时间点及来源。未知日期和未知录入时间不猜测。备份/导入导出须同时包含日期、原始历史时间、操作时间戳、领取数量和来源。

## 2. 词语和提示

用户界面用「张数」「成员张数」，移除「实物」术语以及重复的“按发生时间”“多人合影只计一次”等说明。总张数按记录计算；成员张数按参与关系计算，人数增加不增加这笔记录的张数。计算区别保留在规则和验收中，页面用指标标题区分。

## 3. 成员和属性

参与成员用下拉选择，选项显示团体前缀，并可按团体组织选项。支持多人记录：逐个加入，已选项以可移除标签展示；不把全部成员平铺为几十个勾选项，同一身份不能重复添加。真实 Flutter 应采用可搜索、可多选、限高滚动的选择面板；HTML 原型使用原生下拉及已选标签。

签名显式提供「带签」「无签」，互斥，快捷新建默认带签。背签、宿题继续独立，可与签名选择组合，不决定领取。编辑必须载入原值，不能用新建默认值覆盖原属性或成员。

## 4. 领取的三个选择

界面分别显示「已领取」「部分领取」「未领取」。新建默认已领取。未领取的已领数量为 0；部分领取大于 0 且小于总张数；已领取等于总张数。分次领取记录各批数量，总数守恒，多人记录共享这组数量。

用户允许初始已领取采用录入时间或不设领取时间。本轮采用“不设领取时间”的允许方案，仍待用户偏好复核：初始已领取不展示、不要求、不自动生成实际领取时间。逻辑上标明 `origin=initial`，不能将无时间的已领数量误判为未领，也不能把录入时间伪装为实际领取时间。

之后从未领取/部分领取补领的数量，仍记录实际领取时间。部分领取批次需填写张数与领取时间；原已知实际时间保留，不因表单默认已领取而清除。旧已领但时间未知的历史与“初始已领取不追踪时间”来源应可区分，旧事实不补造。领取日期不能早于发生日期，同一日不比较不存在的发生时刻；只改领取时间不移动数量统计。

本条取代 WF-008 中“所有新录已领必须填写实际时间”的要求；完成维度仍已删除。领取和属性为独立信息。

## 5. 默认扣券及数量联动

新建默认「记录并扣券」，仍允许主动选择「仅记录，不扣券」。按参与成员及张数给基础券建议，券种带团体标识；分配明细可展开，各券池数字独立修改。改变人数或张数后重新给出当前需求的建议；手改单池不改变另一池，差额、超库存及缺券种不能提交。

原型券池仍是合成固定库存：晨星 A 基础券限时4/长期8，晨星通用券长期2。A 默认基础券，B 可选晨星通用券；没有适用券种的成员明确提示，可选择仅记录，不假造库存。共同使用同种券时先合并所需量再校验可用量。确认只更新演示记录，不扣减库存、不代表真实成本事务完成。

真实版本中，补录过去日期的库存时点与回放策略仍须按 DEC-010 裁决；默认扣券不等于可跳过库存/成本预检。已有记录编辑保留原券关联，后续原子纠错仍由相依工作包承接。

## 6. 验收与实施影响

新建首屏日期为 date 输入；签名=带签、领取=已领取、用券=扣券且无初始领取时间输入。可加入多个团体前缀成员、移除/重新加入而不重复；无签能保存和编辑，返回记录保留输入。确认新建保留实际录入时间，编辑日期保留原录入时间并另记修改时间。

部分领取缺时间、已领超额、部分领取等于总量均拒绝；从未领补领填实际时间。改发生日期重新归属统计，改领取时间不改变归属。多人、共享券池、独立池差额、无适用券、窄屏及既有五范围需核对。
