# 统计总花费字号与单行时间筛选修复

2026-10-26，用户在15016覆盖轮追加两项反馈，明确先排fix。仅问题记录→分析评估→MasterSheet规划；下一唯一 **v1.5.1-r7 / M5 / 产品1.2.0**，依赖已完成本地/签名的r6，放M5检查点前。0.5–1人日，23主线累计69.5–118、M5本段21.5–37。拟1.2.0-rc.13/code至少15017仅计划，无新APK；定时PAUSED保持。

## 现象与原因

1. 总花费过大。用户指定与成员模式「成员参与 xx 张」一行同样字号。r6共享容器后，SpendingPanel的expense-total采用headlineLarge（主题40sp），而成员参与说明继承bodyMedium（主题15sp），造成总额过度突出；金额计算本身无变化。
2. 时间筛选同时有今日和日，且点击日以当前anchor进入日范围，anchor在当天时与今日重合。BiPage先渲染bi-today，再遍历全部BiScope.values，其中再次包含day；外层Wrap会换行。只需调整可见控件，不删除底层日查询能力或改写记录日期。

## 完整范围

- 统计「成员花费／团体花费」两种模式的总花费均改为与「成员参与 xx 张」相同的bodyMedium字号，当前主题为15sp，沿正常系统文字缩放；仅对齐字体尺寸，不借此改字重、颜色或布局。保留金额/元舍入、已有内容和总额位置；不把成员总张数、各成员行或全局headlineLarge一起缩小。SpendingPanel在管理报表/成员每日页复用时总额字号同步，避免同一组件不一致；旧独立SpendingPage若仍保留受控入口，审查其总额同源字号，不扩大导航改版。
- 时间选项仅保留 **今日／周／月／年／所有**，删除可见「日」按钮，唯一日快捷为今日。今日点击按上海业务时钟定位当天，并保留其他筛选；周/月/年/所有原规则不变。
- 时间选项固定单行，标准字号320–430优先五项同屏；不足时提供横向滚动，大字仍单行，不缩小字号、不裁按钮或挤掉点击区。仅时间控件由Wrap改为单行策略；成员/成员花费/团体花费这一组仍沿r6自适应，不把用户范围扩大为全部按钮强塞单行。
- 保留BiScope.day、日历选取历史日和前后日导航、记录发生日统计、期间标题及导出元数据。由今日进入日模式后可用日历/箭头看过去日期；历史日时今日不假称当天选中，日期范围标题准确显示所选日，不重新生成第二个「日」按钮。该历史日选中状态作为可逆展示边界待用户体验检查，不阻其余明确工作。
- 共用BiPage的管理报表日期控件同步。日期、成员、团体及更多筛选在三个统计视图切换/返回/清条件时保持原契约；每日与饼图、同人实际张数分母、细边、成本库存及CSV位置保持。
