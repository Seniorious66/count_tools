## 现象与原因

1. 总花费过大。用户指定与成员模式「成员参与 xx 张」一行同样字号。r6共享容器后，SpendingPanel的expense-total采用headlineLarge（主题40sp），而成员参与说明继承bodyMedium（主题15sp），造成总额过度突出；金额计算本身无变化。
2. 时间筛选同时有今日和日，且点击日以当前anchor进入日范围，anchor在当天时与今日重合。BiPage先渲染bi-today，再遍历全部BiScope.values，其中再次包含day；外层Wrap会换行。只需调整可见控件，不删除底层日查询能力或改写记录日期。
