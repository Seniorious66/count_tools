# 信息可空与后续补录

2026-10-12 用户明确要求：正式或合适版本交付前，允许任何条目的业务信息为空。旧备份缺少新字段时，先按原有信息录入，再在 App 内补齐。当前裁决为 MasterSheet DEC-045。

## 生效规则

- 名称、团体、成员、颜色、尺寸、发生日期、张数、签名分类、背签、领取信息、领取时间、备注及后续金额等业务信息均可未知。整条业务信息为空也可以保存。
- 缺失保留 NULL 或原有缺键；未知数量不是 0，未知领取不是未领取，未知签名不是有签，未知日期不是今天。占位文案和展示用颜色不写成事实。
- 系统仍生成内部 ID、保存/修改动作时间、操作标识和修订历史。这些保障追溯，不代表事件发生时间或过去的领取时间。
- 「新增记录」保留已确认的快捷默认；默认字段可以清空。「补录旧信息」从空信息开始；编辑从原信息开始，两者均不套快捷默认。
- 不完整性逐字段计算，并显示待补录内容。它不是新领取状态；已领、部分领、未领的已有规则保留，另允许未知。
- 补齐保留记录 ID、初次录入时间、旧字段原文、原始 ID/ext/未知数据及历史版本。没有授权或已确认映射时，不把旧价格当成本、旧明细条数当 Cheki 张数、旧完成标记当领取事实。
- 未填写不拦截保存；填写了则验证类型、日期、正数、有效引用、同人参与限制、背签条件和已知领取数量。可留存不完整条目，不代表能执行无法验证的扣券、交换或库存修正。
- 不随候选号、M1/M2/M4 或正式发布自动恢复必填。合适版本交付前复核是否需要收紧；后续收紧需明确规则与旧条目兼容方案，既有空信息仍须可读、可编辑、可恢复。

## 已实施入口和边界

当前源码入口为「管理 → Cheki记录 → 补录旧信息」。记录与核对仍两页，可保存全空业务信息，重开后修改；名单、尺寸来自实际管理服务，已有记录通过修订保存补齐内容。新条目即使缺信息，仍有独立身份，不按同名或空字段合并。

团体/同人标签/尺寸名称可空；成员名称、团体、Person 关联及颜色可空。未知团体可在同一成员身份上补齐；已知归属变化继续使用转团新增身份。已经填写的未知字段原文和历史保留，显示「未填写」只作提示。

`RecordInformation` 是可保存信息契约，`RecordDraft` 保留完整快捷录入的校验用途。实际保存服务不调用完整草稿来强制补齐；`legacy_raw` 和其他未知 JSON 键可以保存原事实，修改只覆盖明确变化的业务字段。领取批次的数量、来源、实际时间可分别未知，已知数量仍不能超领。

旧库批量分类映射和导入继续在 M4；本轮没有读取设备或把真实备份写入新 App。手动补录可用已知事实/备注起步；真实历史原档迁入要经过映射预览，不能声称旧备份已完成迁移。

## 统计与事务接入

| 指标/动作 | 使用条件 | 未知信息处理 |
| --- | --- | --- |
| 全部已知张数 | 张数已知 | 单列张数未填写的记录数 |
| 日/周/月/年张数 | 发生日期和张数已知 | 日期缺失单列；不落在录入日 |
| 成员张数 | 张数与成员身份已知 | 未知成员不创建假身份，也不阻止计算其他已知维度 |
| 属性与领取分布 | 对应属性或领取事实已知 | 未知单列，不分入有签或未领 |
| 已领/未领张数 | 总量及领取数量均已知 | 只知道状态时不造已领数量 |
| 成本/库存/扣券 | 该动作必要来源、归属和数量可校验 | 可保存条目信息，不能制造 0 成本、0 库存或执行猜测交易 |

当前入口提供全部已知张数及缺数量/日期计数；M1 首页月份/筛选/每日汇总和完整批次操作仍在 v1.2.1 接续。M3 完整 BI、M2 券事务、M4 批量迁移沿此规则实施，不用字段齐全过滤掉本来可以统计的已知事实。

## 必验场景

1. 全空业务条目保存、关闭重开、显示待补录；技术身份和保存时间存在。
2. 只有原信息的记录保存，新增字段无日期/张数/签名/领取默认，原文/ext/未知值往返保留。
3. 补齐日期、数量、成员等字段，ID/录入时间不变，修订历史能读回补齐前空值。
4. 清空字段仍可保存；已知指标和待补录计数随对应字段更新，领取时间不替代发生日期。
5. 全空实体和未知归属的成员保存、重开、补齐；已有同人合影的关联修改不能制造重复身份。
6. 错误格式、悬空引用、非法属性和超领拒绝，输入保留；故障回滚整笔写入，重复操作不重复记录。
7. schema 4→5 保留全部原行、历史、扩展列/BLOB、索引和触发器；故障事务回滚。无法安全支持的未知外部引用拒绝迁移，保留原库。
8. 当前 schema 的全库、设置、附件完整往返与新进程读取相等；NULL、缺键和历史事实不被补默认。

本地测试、签名构建和手机验收分别登记；此兼容改动不将整个 v1.2.1 或 M1 自动标为完成。
