## 原问题和原因

用户明确：“花费和切数统计应该在同一个位置”，“花费和成员是同一个tier”，类似此前成员/同人关联的按钮选择。另要求统计颜色统一黑色极细边。

r5虽然将成员花费/团体花费改成ChoiceChip，但SpendingPanel独立一块，之后又常驻成员张数排行，实际形成上下两个统计区域。自动测试只证实两个花费按钮原地切换，未覆盖“与成员张数同层、同一输出区域”，因此r5本地通过不能当这个用户语义已满足；保留其451回归/安装证据，不回写为本需求通过。

## 同层、同位置

- 一排同层选择 **成员／成员花费／团体花费**，默认成员。复用原ChoiceChip风格；窄屏大字允许按钮换行，语义仍同一组。
- 按钮下方只保留**一个共用统计主体（摘要＋结果列表）**：成员模式显示张数/参与及成员排行、已关联身份展开、描述/百分比/进度；成员花费模式同位置显示消费金额和成员花费列表；团体花费模式同位置显示消费金额和团体花费列表。切换替换主体，不另插花费卡片，也不在花费列表下面同时常驻第二套成员张数排行。成员张数与花费是同层视图，不再只在花费卡片内部切两个维度。
- 期间/日期/团体/更多筛选在共用控制区保留，三种视图共享其状态，切换不跳页面、不丢筛选。返回统计页保留该页面当次选择，首次默认成员，不新增持久化设置。
- 每日张数、饼图继续沿已有位置和口径，不复制一套全页或擅自新增花费趋势；共同费用、原记录/赠送明细及管理导出能力保持可达，不重新常驻CSV。费用列表沿现有金额降序，张数列表沿现有张数降序。
- r5已确认的同人聚合、当前在用主名、各身份展开、原团体归属和主子行百分比分母保持：20张下3/2张为15%/10%、主行25%。不得将金额、人数参与分母和实际张数混用。

## 黑色极细边缘

统计数据图形的成员色块、进度条填充、饼图各扇区及颜色圆点/图例统一黑色极细描边，**0.5dp作为初始可逆视觉参数**，在真实像素比下保持可见且不粗重。白色、浅粉/浅蓝、相同色相邻均有清楚边界；保留原成员颜色值，不暗化/替换白色，不改变成员颜色设置。

分别审查CountRow填充边缘、MemberPie外圈及相邻扇区边界、花费成员颜色圆点、每日/成员日视图的数据标记。描边只用于统计图形，不给全部文字或按钮强加描边，不扩大为全局主题改版。饼图保留有效色错排、图内标签及小比例门槛，细边不能遮掉小扇区或改变比例几何；未知/0量不制造色块。展开行和父行应一致，窄屏和200%不把描边按文字缩放加粗。
