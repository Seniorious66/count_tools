# 周统计按自然周

2026-11-07 · ROUND-20261107-CALENDAR-WEEK-PLAN-01 · DEC-094 / RISK-046。用户明确：「按周统计不能按滚动七天啊，周一到周日啊」。并入尚未开工的 **v1.5.1-r9 / M5**，原限时券六位日期范围、依赖、0.5–1 人日和候选计划保留。

「周」始终取选定日期所在的自然周，包含周一、周日；切换前后周按整周移动。当日锚点沿用现有上海业务日期，选历史日期则统计该日所在周。按记录发生日期归属。日、月、年、所有的行为及原数据不变。

源码 `BiPeriod` 已从锚点回推到周一，周日为周一加六天；`BiPage` 的日期范围、统计查询和花费共用该期间。已有跨年算法用例。本轮只读源码，未执行测试或复现用户手机上的差异。r9 先逐入口复核锚点、显示和取数，只有发现偏差才修改对应路径，不重写已符合口径的算法。
